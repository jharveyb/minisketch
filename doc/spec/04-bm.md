# 4. Berlekamp–Massey on the odd syndromes

`BerlekampMasseyOdd(osyn, n_syn, max_degree)` (`src/sketch_impl.h:2623`)
returns the connection polynomial Λ (Λ_0 = 1) of the shortest LFSR
generating S_1..S_(n_syn), given only the odd syndromes
osyn[j] = S_(2j+1), or failure if its length would exceed `max_degree`.
The result, including the failure, is exactly that of textbook BM over all
n_syn syndromes with S_(2k) = S_k^2 (C48). Decode calls it with
n_syn = 2c and max_degree = `max_elements`; the power-sum split (chapter 5)
calls it on derived power sums.

The input need not be the sketch of a set: every claim below holds for any
sequence with S_(2k) = S_k^2, which is the case by construction since the
even terms are computed from the odd ones.

## Textbook BM (the reference)

`berlekamp_massey` in `tests/pyminisketch.py`, with L = |current| − 1:

```
current = [1]; prev = [1]; b_inv = 1
for n in 0 .. N-1:                                # syn[n] = S_(n+1)
    d = syn[n] + Σ_{i=1}^{L} current[i] · syn[n-i]
    if d != 0:
        x = n + 1 - L - (|prev| - 1)
        if 2L <= n:                               # length change
            tmp = current
            grow current to length |prev| + x     # new L = n + 1 - L
            current[i + x] ^= d·b_inv·prev[i]   for all i
            prev = tmp; b_inv = 1/d
        else:
            current[i + x] ^= d·b_inv·prev[i]   for all i
return current
```

With the max_degree failure: fail if the final L exceeds max_degree. Since L
never decreases, failing as soon as a length change would exceed it is
equivalent; the C++ checks `|prev| + x − 1 > max_degree` before growing.

## Even steps are skipped (C12)

For any sequence with S_(2k) = S_k^2, the discrepancy at every even
position S_(2k) is 0, so BM makes no update there. The C++ loop still
appends S_(n+1) to its syndrome array at every n (computing
syn[n] = syn[n/2]^2 for odd n, i.e. S_(n+1) = S_((n+1)/2)^2), but computes a
discrepancy only for even n (odd-indexed S). (Proof sketch: BM's iterates
satisfy Λ·S ≡ xΛ' mod x^(n+1); lengths change only at odd positions; at an
even position the discrepancy is a coefficient of an odd series times an
even one, which is 0.)

## The C++ iteration

```
BerlekampMasseyOdd(osyn, n_syn, max_degree):
    current = [1]; prev = [1]; b = 1; b_inv = 1 (valid)
    next_verify = BM_VERIFY_MIN_PREFIX                    # 0
    for n in 0 .. n_syn-1:
        syn[n] = osyn[n/2] if n even else syn[n/2]^2      # S_(n+1)
        if n odd: continue                                # C12
        d = syn[n] + Σ_{i=1}^{L} syn[n-i]·current[i]      # lazy on CLMUL fields
        if d != 0:
            x = n + 1 - L - (|prev| - 1)
            if b_inv not valid: b_inv = Inv(b)
            swap = (2L <= n)
            if swap:
                if |prev| + x - 1 > max_degree: return FAIL
                tmp = current; resize current to |prev| + x (zero-filled)
            current[i + x] ^= (d·b_inv)·prev[i]   for i < |prev|
            if swap: prev = tmp; b = d; b_inv invalid
        else:
            done = n + 1                                  # syndromes processed
            if done >= next_verify and done >= 2L + 2 and n_syn - done >= 32:
                if VerifyTail(current, osyn, j0 = n/2 + 1, j_end = (n_syn+1)/2):
                    break
                next_verify = done + done/2
    if current is empty or its last coefficient is 0: return FAIL
    return current
```

The constants are `BM_VERIFY_GAP` = 2 (`done ≥ 2L + GAP`),
`BM_VERIFY_MIN_PREFIX` = 0 and `BM_VERIFY_MIN_TAIL` = 32 (chapter 7). The
inverse of b is computed lazily, once per length change that is followed by
another update.

On generic fields the C++ also builds one Multiplier table per processed
syndrome (kept in a deque, so the tables of the walked prefix only) and
computes the discrepancy as Σ table[n−i](current[i]); on CLMUL fields it is
one lazy dot product. The update multiplies prev by a fresh Multiplier of
d·b_inv in both cases.

The final check fails if Λ_L = 0 (the polynomial's length exceeds its
degree). See C37: a decode that would otherwise succeed never has Λ_L = 0.

## Early termination and the tail check

**When.** After a zero discrepancy at odd S_(n+1), with done = n + 1
syndromes processed (and the even S_(n+2) implied), the code attempts a tail
verification if done ≥ next_verify, done ≥ 2L + 2 and at least 32
syndromes remain. If the check passes, BM stops and returns `current`. If
it fails, BM resumes where it was, and the next attempt waits until
done ≥ 1.5 × done_at_failure (geometric back-off, so a failing check costs
at most a constant factor overall).

**What.** `BerlekampMasseyVerifyTail(conn, u, j0, j_end)`
(`src/sketch_impl.h:2462`) returns whether

```
u_j + Σ_{a=1}^{L} conn_a^2 · u_(j-a) = 0    for all j in [j0, j_end)
```

where u_j = osyn[j] = S_(2j+1) and L = deg conn ≤ j0. That is, the stored
odd syndromes satisfy the recurrence with connection polynomial Λ^(2)
(each coefficient squared): u_j = Σ_m m·(m^2)^j is an LFSR sequence with
roots m^2 (C16). Here j0 = n/2 + 1, the first odd syndrome not yet
processed (S_(n+3)), and j_end = (n_syn + 1)/2 = c.

**Why it is exact.** Let C = Λ·S. BM has verified C_k = 0 for
L < k ≤ P with P = n + 2 ≥ 2L (the even S_(n+2) is free by C12). The
identity Λ·C = C^2 + Λ^2·S_odd (C13) together with the even-position
recurrence C_(2j) = C_j^2 + Σ_(i≥1) Λ_i C_(2j−i) (C14) gives, by induction
over the positions past P: C_k = 0 for all L < k ≤ n_syn iff the odd-only
check above holds at every odd 2j + 1 in (P, n_syn] (C15). So when the check
passes, textbook BM would see zero discrepancies for the rest of the
sequence and return the same Λ; when it fails, resuming BM is the textbook
iteration. Either way the result, including the max_degree failure, is
textbook BM's (C48). The oracle `bm_odd` / `verify_tail_odd` in
`tests/pyminisketch.py` implements exactly this check (with a simpler
attempt schedule).

## Tail check tiers

All tiers compute the same predicate and stop at the first violated block
(L = deg conn; conn2 = conn with squared coefficients). In order of the
code:

| tier | applies when | method |
|---|---|---|
| lazy Karatsuba | CLMUL, 64 ≤ L < 512 | blocks of n positions, each one middle product |
| lazy direct | CLMUL, L < 64 | per position dot product, 4 positions at a time |
| table direct | generic, not (FFT-capable and L ≥ 40) | Multiplier per coefficient, L1-sized blocks |
| FFT | FFT-capable, L ≥ 512 (CLMUL) or L ≥ 40 (generic) | blocks, conn2 transformed once |
| Karatsuba blocks | CLMUL with L ≥ 512 on a field that is not FFT-capable, or the FFT tier with 2^fft_m > 2^b (below) | blocks, full products |

The thresholds are `BM_VERIFY_KARA_MIN_DEGREE` = 64,
`BM_VERIFY_FFT_MIN_DEGREE` = 512 (cheap multipliers) and
`BM_VERIFY_FFT_MIN_DEGREE_TABLE` = 40 (generic). "FFT-capable" is
b ∈ {16, 32, 64} (chapter 3).

**Lazy Karatsuba** (C17). Choose n = b'·2^k ≥ L + 1 with b' ≤ 16: start
b' = L + 1, k = 0 and halve b' (rounding up), incrementing k, while
b' > 16 (`MP_BASE`); then the middle-product recursion halves exactly down
to direct kernels. Store crev[n − 1 − a] = conn2[a] for a ≤ L (zeros at the
front). For p = j0, j0 + n, …: with the window w = u[p − n + 1 .. p + n − 1]
(2n − 1 entries; positions outside [0, j_end) read as 0, which only happens
at the last block since p − L ≥ j0 − L ≥ 0), mp(crev, w, n)_s =
Σ_a conn2_a·u_(p+s−a). Check Reduce(out_s) = 0 for s < min(n, j_end − p).

**Lazy direct.** For each j, Reduce(WideFrom(u_j) ⊕ ⊕_{a=1}^{L}
MulWide(conn2_a, u_(j−a))) = 0; four consecutive positions share each
coefficient load.

**Table direct.** One Multiplier per nonzero conn2_a for the whole tail;
positions in blocks of 512; acc = u[p .. p+B), then for each a,
acc[t] ^= mul_a(u[p + t − a]); every acc must be 0.

**FFT and Karatsuba blocks.** With fft_m = the least m with
2^m ≥ 4(L + 1), set to 0 (no FFT) if not using the FFT or if fft_m > b.
Block size B = 2^fft_m − 2L with the FFT, else max(2L, 64). For each block
starting at p, the window win = u[p − L .. p + B') (B' = min(B, j_end − p))
times conn2 puts position j at product index j − p + L; check
prod_i = 0 for L ≤ i < L + B'. With the FFT, conn2's 2^fft_m-point
transform is prepared once and each block costs one forward and one inverse
transform (the product has length ≤ B + 2L ≤ 2^fft_m, so no wraparound);
without it, `TraceModPolyMulFull(conn2, win)`.

## Cost (C18, informative)

The serial BM part is O(n^2) for n set elements, plus the tail check:
O(c·n) direct, O(c·n^0.585) lazy Karatsuba, O(c·log n) FFT. Before these
changes BM was a serial O(c·n) loop over all 2c syndromes, which dominated
decode when n ≪ c. Measured gains are in `doc/optimizations.md`
("Frobenius-structured Berlekamp-Massey", "Measured").

## max_degree failure

`BerlekampMasseyOdd` fails (returns the empty vector) when a length change
would make L > max_degree. Decode passes max_degree = `max_elements`, so a
sketch whose shortest LFSR is longer than `max_elements` fails in BM,
exactly as the textbook decoder fails when L > max_elements. In
`PowerSumSplit` the bound is M = two_m/2, and a failure there only means
"try the other side" (chapter 5).
